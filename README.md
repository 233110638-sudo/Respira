# Respira

Aplicación Flutter de bienestar emocional con un flujo de bienvenida y consentimiento, chequeo de estado de ánimo, recomendaciones, ejercicio guiado de respiración, orientación para acompañar a alguien y una pantalla de ayuda en crisis.

## Ejecutar

1. Instala Flutter y configura un dispositivo o emulador.
2. Ejecuta `flutter pub get`.
3. Ejecuta `flutter run`.

La aplicación funciona localmente y no requiere cuenta, Firebase ni servicios externos. No reemplaza atención profesional ni servicios de emergencia.
