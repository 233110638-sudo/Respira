# Respira
Respira es una aplicación hecha con Flutter que ofrece herramientas sencillas para el bienestar emocional. Incluye ejercicios y orientación para buscar apoyo cuando sea necesario.

## Integrantes
- Missael
- Aldo
- Randy

## Funciones principales
- Chequeo de bienestar con recomendaciones generales.
- Ejercicio guiado de respiración 4-7-8.
- Ejercicio Grounding 5-4-3-2-1.
- Artículos breves sobre bienestar emocional.
- Consejos para acompañar a alguien.
- Acceso a información de ayuda en situaciones difíciles.

## Cómo ejecutar la aplicación

flutter pub get
flutter run

## Estructura de carpetas


lib/
	screens/      Pantallas de la aplicación
	widgets/      Componentes reutilizables
	core_theme.dart
	main.dart
test/           Pruebas
img/            Capturas de pantalla
android/        Archivos para Android
ios/            Archivos para iOS
web/            Archivos para web


## Aviso importante
Respira no da diagnósticos ni sustituye la atención de un profesional de la salud. Si necesitas ayuda urgente, contacta a los servicios de emergencia de tu localidad.
